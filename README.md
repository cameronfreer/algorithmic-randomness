# Algorithmic randomness

Formalizations in algorithmic randomness, in [Lean 4](https://lean-lang.org/)
building on [mathlib](https://github.com/leanprover-community/mathlib4).

## Building

Requires [elan](https://github.com/leanprover/elan); the toolchain
(Lean 4.32.2) is pinned in `lean-toolchain` and mathlib is pinned to the
matching `v4.32.2` tag.

```
lake exe cache get
lake build
```
